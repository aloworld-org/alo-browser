Made here, 2026-10-06, rather than taken from a page.

Why not a page. Item 180 is the same stripes in two more formats, judged by the
same tests as `a-picture`'s PNG and JPEG — so the picture must be the one those
tests already know, red, green and blue in eight-row bands, and a picture a
site happened to serve would not be. Nothing here touches the network, and
anybody can re-derive every file from the script below.

What made them. Pillow 10.4.0 with libwebp 1.4.0, run on `a-picture`'s
`stripes.png` — an encoder that shares no code with the decoders this engine
rents (`gif`, `image-webp`), so a mistake the two sides of one library agree on
cannot hide here. The script, exactly as run:

```python
import sys
from PIL import Image

src, out = sys.argv[1], sys.argv[2]
stripes = Image.open(src).convert("RGBA")
red, green, blue = (220, 40, 40), (40, 180, 60), (40, 80, 220)

# The blue stripe see-through: a picture with transparency in it.
clear = stripes.copy()
for y in range(16, 24):
    for x in range(24):
        clear.putpixel((x, y), (0, 0, 0, 0))

# A second frame that is unmistakably not the first: the stripes upside down.
flipped = stripes.transpose(Image.FLIP_TOP_BOTTOM)

stripes.convert("RGB").save(f"{out}/stripes.gif")
clear.save(f"{out}/stripes-clear.gif")
stripes.convert("RGB").save(
    f"{out}/stripes-moving.gif", save_all=True,
    append_images=[flipped.convert("RGB")], duration=500, loop=0,
)
stripes.convert("RGB").save(f"{out}/stripes.webp", quality=90)
stripes.convert("RGB").save(f"{out}/stripes-lossless.webp", lossless=True)
clear.save(f"{out}/stripes-clear.webp", quality=90)
stripes.convert("RGB").save(
    f"{out}/stripes-moving.webp", save_all=True,
    append_images=[flipped.convert("RGB")], duration=500, loop=0, quality=90,
)
```

run as `python3 -I freeze.py ../a-picture/stripes.png .`.

What each is for.

- `stripes.gif` — GIF87a, a palette of three. The plain case.
- `stripes-clear.gif` — GIF89a with a transparent index: the blue stripe is
  see-through, and the page's colour shows where it was.
- `stripes-moving.gif` — two frames, the second the stripes upside down. Drawn
  as its first frame, so red is on top.
- `stripes.webp` — lossy, the simple kind: one `VP8 ` chunk.
- `stripes-lossless.webp` — lossless, the simple kind: one `VP8L` chunk.
- `stripes-clear.webp` — the extended kind: `VP8X`, an `ALPH` chunk and a
  `VP8 ` one, blue stripe see-through.
- `stripes-moving.webp` — extended and animated: `ANIM` and two `ANMF` frames,
  the second upside down. Drawn as its first frame.
