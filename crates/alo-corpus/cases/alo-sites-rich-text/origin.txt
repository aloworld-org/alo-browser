differently by one.

## What it found

**A list inside a list stood a line's height below the point it belongs to.**
The sheet gave every `ul`, `ol` and `menu` `margin: 1em 0`, nested or not, so
"Keep supporting detail nested" was 16 pixels below "Make the next step
visible" and every block after it 16 lower than a browser draws it. HTML's
rendering section gives a list in a list `margin-block: 0`. Queue item 400.

**The finished task was not struck out.** `<s>Publish</s>` drew as plain
text: the sheet had no rule for `s`, `del`, `u` or `ins`, so an edit looked
like no edit and a done task like one still to do. Queue item 400.

**There are no list markers at all** — no bullets, no "3." and "4.", no
hollow bullet on the nested point. This engine makes no `::marker` (ADR 0043,
*What this does not decide*). Queue item 401, which needs its ADR.

Rendered at 800 × 600, as the alo Sites cases are.
